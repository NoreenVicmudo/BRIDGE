# BRIDGE
# Board Readiness Intelligence and Data Governance Engine is a central repository of all board performing programs in Manila Central University. 
# Information such as their demographic, academic, and board preparation are recorded and grouped for users to analyze the relationships and comparison.
# Report generation allows user to generate graphs based on the statistical analysis selected.
# Users can import students through csv file and export the reports generated.
